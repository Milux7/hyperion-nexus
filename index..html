Arquitectura y Especificaciones

Microcontrolador

Placa Arduino UNO R3 (ATmega328P @ 16MHz) encargada de la telemetría y procesamiento de tiempo de eco.

Sensor HC-SR04

Sensor ultrasónico de 40kHz con rango de medición de 2 cm a 200 cm en la lógica programada.

Matriz de 8 LEDs

4 Verdes, 2 Amarillos y 2 Rojos conectados a pines digitales independientes con resistencias de 220 Ohm.

Código Fuente C++ 

const int PIN_TRIG = 9;
const int PIN_ECHO = 8;
const int PIN_BUZZER = 3;
const int PINES_LEDS[] = {2, 4, 5, 6, 7, 10, 11, 12};
const int TOTAL_LEDS = 8;
const int UMBRALES[] = {200, 175, 150, 125, 100, 75, 45, 15};

void setup() {
  Serial.begin(9600);
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  for (int i = 0; i < TOTAL_LEDS; i++) pinMode(PINES_LEDS[i], OUTPUT);
}

void loop() {
  digitalWrite(PIN_TRIG, LOW); delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  
  long duracion = pulseIn(PIN_ECHO, HIGH, 30000);
  float distancia = (duracion == 0) ? 400.0 : (duracion * 0.0343) / 2.0;

  for (int i = 0; i < TOTAL_LEDS; i++) {
    digitalWrite(PINES_LEDS[i], (distancia <= UMBRALES[i]) ? HIGH : LOW);
  }
  delay(100);
}
