Arquitectura y Especificaciones del Sistema

Detalles técnicos del diseño de hardware y principios físicos del HYPERION NEXUS v2.5.

Unidad de Procesamiento

Basado en Arduino UNO R3 (Microcontrolador ATmega328P @ 16MHz). Procesa el pulso de eco del sensor y calcula la distancia con precisión en un ciclo continuo.

Sensor Ultrasónico HC-SR04

Emite ráfagas ultrasónicas a 40 kHz. Mide el tiempo de retorno del eco. Rango calibrado de 2 cm a 200 cm con ángulo de apertura de 15°.

Barra Espectral de 8 LEDs

Matriz de 8 componentes ópticos (4 Verdes, 2 Amarillos, 2 Rojos). Lógica inversamente proporcional: conforme el objeto se acerca, más LEDs se encienden.

Respuesta Acústica PWM

Piezo Buzzer transductor calibrado por modulación PWM. Genera beeps progresivos y conmuta a tono continuo en zona crítica (< 15 cm).

Protección de Corriente

Cada nodo emisor de luz está acoplado con una resistencia de limitación de 220 Ohmios, protegiendo los pines de salida del Arduino.

Telemetría Serial

Transmisión de datos via interfaz UART Serial a 9600 Bauds, permitiendo monitoreo en tiempo real desde terminales externas.

Esquema Completo de Cableado y Mapeo de Pines

Guía paso a paso para la conexión física de todos los componentes sobre la placa Arduino UNO R3.

Código Fuente Oficial (Arduino C++)

Firmware listo para compilar e implementar desde el IDE de Arduino.

const int PIN_TRIG = 9;
const int PIN_ECHO = 8;
const int PIN_BUZZER = 3;

const int PINES_LEDS[] = {2, 4, 5, 6, 7, 10, 11, 12};
const int TOTAL_LEDS = 8;
const int UMBRALES[] = {200, 175, 150, 125, 100, 75, 45, 15};

void setup() {
  Serial.begin(9600);
  
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_BUZZER, OUTPUT);

  for (int i = 0; i < TOTAL_LEDS; i++) {
    pinMode(PINES_LEDS[i], OUTPUT);
  }

  Serial.println(F("[HYPERION NEXUS v2.5] - Sistema listo y operativo."));
}

float medirDistancia() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);

  long duracion = pulseIn(PIN_ECHO, HIGH, 30000); 
  if (duracion == 0) return 400.0;

  return (duracion * 0.0343) / 2.0;
}

void loop() {
  float distancia = medirDistancia();

  Serial.print(F("Distancia: "));
  Serial.print(distancia);
  Serial.println(F(" cm"));

  int ledsEncendidos = 0;

  for (int i = 0; i < TOTAL_LEDS; i++) {
    if (distancia <= UMBRALES[i]) {
      digitalWrite(PINES_LEDS[i], HIGH);
      ledsEncendidos++;
    } else {
      digitalWrite(PINES_LEDS[i], LOW);
    }
  }

  if (ledsEncendidos == TOTAL_LEDS) {
    tone(PIN_BUZZER, 2300); 
    delay(60);
  } else if (ledsEncendidos > 0) {
    int retardo = map((int)distancia, 15, 200, 40, 350);
    tone(PIN_BUZZER, 1200, 30);
    delay(retardo);
  } else {
    noTone(PIN_BUZZER);
    delay(100);
  }
}
